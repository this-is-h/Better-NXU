# Better NXU 文档

本文档按读者分为两组：

- [用户文档](user/README.md)：安装、首次配置、功能使用、课表工具、隐私与常见问题。
- [开发者文档](dev/README.md)：架构、模块 API、数据格式、设计决策、开发测试与发布流程。

项目根目录的 [README.md](../README.md) 是项目简介，[CONTRIBUTING.md](../CONTRIBUTING.md) 是贡献入口，[SECURITY.md](../SECURITY.md) 是安全报告入口。本目录中的文档以当前 `src/` 模块化源码为准，提供更完整的操作和维护细节。

现有的 [架构审计与优化报告](dev/architecture-review.md) 记录了重构期间发现的问题、已经完成的修复和剩余风险，适合在阅读开发者文档后继续查看。
