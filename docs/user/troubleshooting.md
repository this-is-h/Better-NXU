# 常见问题与排障

## 1. 点击安装时出现油猴/Tampermonkey 页面

立即取消。Better NXU 只支持 ScriptCat。禁用其他用户脚本管理器对 `.user.js` 的接管，确认 ScriptCat 已启用，再从 [ScriptCat 的 Better NXU 项目页](https://scriptcat.org/zh-CN/script-show-page/1429)重新打开安装文件。

同时安装多个 Better NXU 副本也会冲突。保留一个当前版本，其余全部禁用或卸载，然后刷新页面。

## 2. 脚本安装后完全没有反应

依次检查：

1. ScriptCat 和 Better NXU 都已启用。
2. 当前网址属于支持的宁大域名，而不是搜索引擎缓存、第三方镜像或未匹配的新域名。
3. 刷新页面；用户脚本通常不会补跑到安装前已经打开的页面。
4. 查看 ScriptCat 是否提示远程 `@require`/`@resource` 校验或下载失败。
5. 禁用旧 Better NXU 和其他会修改相同页面的脚本。
6. 打开控制台，查找 `[初始化]`、`[路由]` 或站点前缀日志。

只有某个学校页面失效而其他页面正常，通常是学校修改了 URL 或 DOM。反馈时提供页面地址形态和选择器附近截图，不要提供登录信息。

## 3. 设置/关于/小工具页显示空白或一直“部署中”

这些页面依赖 Vue、Vant CSS 和通知资源。尝试：

- 更新或重新安装脚本，让 ScriptCat 重新缓存资源；
- 检查网络是否能访问脚本元数据中的 CDN；
- 暂时禁用广告拦截、严格 CSP 扩展或其他脚本后重试；
- 确认地址分别是 SSL VPN 的 `/h/settings`、`/h/about`，工具是 WebVPN 的 `/h/tools`。

关于页 README/更新日志失败时应显示纯文本降级提示。资源是在安装/更新脚本时缓存的，仓库文档刚更新并不会立即出现在已安装脚本中。

## 4. 自动登录没有执行

检查相应系统的设置：

- WebVPN/统一认证使用 `WebVPN` 账号、密码和自动登录开关。
- 教务使用独立的 `Jwgl` 账号、密码和自动登录开关。
- 任一账号或密码为空，设置页会自动关闭对应开关。
- 页面已经显示账号/密码错误时，脚本会停止并提示修改配置，不会重复提交。

在非 IDS 的 WebVPN 代理页面，脚本有意不读取或填写 WebVPN 凭证。如果学校启用了新的认证域名或路径，需要更新脚本，不应通过放宽安全检查解决。

## 5. 登录页只填了账号密码，没有自动提交

可能原因：

- 你关闭了自动登录，只使用了右下角填充按钮；
- 页面出现旧式图形验证码，需要手动输入；
- 页面出现滑块验证，自动识别失败或被判定为异常，需要手动完成；
- 学校页面没有加载提交按钮或登录函数；
- 页面已有认证错误，脚本停止避免循环登录。

完成验证后手动点击登录即可。

IDS 滑块若出现 `ort.min.js` 的 MIME 类型为 `text/html` 的错误，请更新脚本后刷新 WebVPN 登录页。新版通过 ScriptCat 后台下载并校验滑块资源，不再经 WebVPN 代理 CDN。首次下载较大；若提示下载或完整性校验失败，可刷新后重试或手动拖动滑块。

如果 `pnpm dev` 中滑块正常，而安装脚本报 `Failed to construct 'Worker' ... cannot be accessed from origin`，请运行 `pnpm build`，在 ScriptCat 中更新 `dist/better-nxu.user.js`，停用开发脚本后完整刷新登录页。修复版从真实页面取得 WebVPN 地址转换器及配套 Blob/Worker API。分别检查 IDS 直连和 WebVPN 的首次识别、再次识别与失败后的手动操作；开发环境通过不能代替安装版验证。

若报 `Unexpected identifier 'ArrayBuffer'`，也是 WebVPN 兼容问题：旧版创建 JavaScript Blob 时未先将二进制解码为文本。更新后需刷新整个登录页，使旧 Worker 和页面模块重新加载；使用 `pnpm dev` 调试时也需要刷新页面。

若出现 `Unexpected token` 或 `Failed to fetch dynamically imported module: blob:https://ids.nxu.edu.cn/...`，说明 WebVPN 改写了本地模块或其 Blob 来源。更新后的脚本会保留模块内容并还原真实 Blob 地址；请完整刷新登录页后重试。

开发者排查此类问题请看[WebVPN 资源加载排障](../dev/webvpn-resource-loading.md)，其中记录了完整修复方法和复现步骤。

## 6. 教务验证码识别很慢或失败

首次 OCR 需要下载 worker、WASM 和英文模型，可能明显变慢。脚本会显示加载阶段，初始化约 45 秒或识别约 30 秒超时后自动降级。

处理方法：

- 检查网络和 CDN 访问；
- 刷新验证码后手动输入；
- 确保教务页面使用 HTTPS 或现代浏览器，WebCrypto/worker 可用；
- 不要连续刷新或重复点击，避免同时启动多个识别任务。

OCR 不是安全验证绕过，只是读取当前页面验证码，准确率受图片变化影响。

## 7. 进入小工具时突然打开两个后台标签页

这是预期行为。工具页会后台打开信息门户和学工系统代理页来建立课表 ID与身份验证所需登录状态，约 5 秒后尝试关闭。浏览器阻止自动关闭时可手动关闭。

这些页面如果要求重新登录，应先完成登录，再回到工具页重新加载课表。

## 8. 教师查询提示登录过期、超时或格式异常

- “WebVPN 登录已过期”：重新登录 WebVPN，并访问一次相关校内代理页面。
- “请求超时/Network error”：检查校园网络或代理状态后重试。
- “结果格式异常”：学校 XML 接口可能变化，属于脚本适配问题。
- 查不到教师：尝试完整姓名；该功能只查询接口中的在职教师数据。

点击新搜索会取消旧搜索，这是正常行为。

## 9. 自动获取个人课表失败

常见原因：信息门户未登录、后台预热尚未完成、门户日历卡片接口变化或缓存课表 ID 过期。

先等待后台标签页完成登录，再重新进入“课表信息”。仍失败时输入门户分享链接/课表 ID，或从教务导出 JSON 上传。

如果缓存了错误 ID，可执行“完全重置”清除，但这也会清凭证和密钥。优先重新登录和输入正确链接；只有确认需要清全量数据时才完全重置。

## 10. “导出 JSON”按钮不可用

工具页只允许导出当前登录账号本人的远程课表：

- 上传的文件不能再次导出；
- 别人的课表链接只能查看；
- 手动链接必须与当前账号缓存的课表 ID 相同。

这是身份完整性限制，不是按钮故障。自己的课表可重新自动加载，或直接在教务系统课表页导出。

## 11. 学号验证一直失败

输入的学号必须与当前 WebVPN 登录账号一致。先确认没有在另一个标签页切换账号，重新登录 WebVPN/学工系统后再试。脚本不会允许使用当前登录态为其他学号生成带身份的导出文件。

## 12. 图片或 Excel 导出失败

图片依赖 snapdom，Excel 依赖 XLSX；两者由 ScriptCat 在安装时加载并桥接。尝试更新/重装脚本、刷新页面并检查资源错误。

教务系统通过 WebVPN 代理访问时也支持课表图片导出。脚本会分批读取截图所需的计算样式、临时内联并修正 SVG 序列化；生成时间仍可能略高于直连环境，页面会持续显示生成提示。

导出前等待课表和字体完全渲染，避免重复点击。Excel 没有成员或课表数据时不会导出。

## 13. 上传 JSON 提示格式无效

确认：

- 文件扩展名为 `.json`；
- 内容是 Better NXU Schema 2.0 或合法加密信封；
- 明文不超过 5 MB，加密文件不超过 7 MB；
- 文件未被聊天软件、编辑器或网盘改写截断；
- 不是 0.x/1.x 旧格式课表。

不要通过手工把 `schemaVersion` 改成 `2.0` 强行导入，其他字段和引用仍可能无效。

## 14. 加密课表打不开

“解密密钥不匹配或文件已损坏”表示：

- 粘贴的不是该公钥对应的私钥；
- PEM 开头/结尾或正文复制不完整；
- 文件内容被修改；
- 发送方使用了另一位接收者的公钥。

让发送方使用你当前页面显示的公钥重新导出，或找到对应旧私钥备份。项目没有私钥找回能力，维护者也无法解密。

## 15. 重新生成密钥后旧文件打不开

这是预期结果。重新生成只保存新密钥对，不保留旧私钥。使用旧私钥备份打开旧文件；如果没有备份，只能让原发送方用新公钥重新导出。

“完全重置”、清理 ScriptCat 数据、卸载扩展、浏览器同步失败或换设备也可能丢失私钥。

## 16. 门户应用中心没有 Better NXU 卡片

确认地址是新版门户并位于 `#/hall`。等待 iframe 中原生应用列表加载；切换到其他页面再切回应触发重新注入。

若持续没有：

- 刷新并重新登录门户；
- 检查浏览器是否阻止 iframe 或跨页面访问；
- 学校可能更改了 `iframe#template-container`、`div.city_sort` 或 `div.sortItem` 结构，需要脚本更新。

### WebVPN 导出图片的周次文字重叠

更新脚本后重新打开课表页并重新导出。此问题来自教室行在截图中意外换行，末尾数字覆盖了下一行周次。脚本现已避免复制样式时小数宽度缩小，保留原有字体和正常换行；已生成的旧图片需要重新导出。

## 17. 知网/万方选中文字没有复制

### 开发脚本报 `__vite-plugin-monkey.entry.js` MIME 错误

若正在使用 `pnpm dev`，并看到入口请求变成 `https://kns.cnki.net/__vite-plugin-monkey.entry.js`、由 Service Worker 返回 `text/html`，这是 zylib 代理接管本地开发请求造成的，脚本主程序尚未启动。

运行 `pnpm build`，在 ScriptCat 中停用 `server:Better NXU`，安装或更新 `dist/better-nxu.user.js`，然后完整刷新阅读页。仅启用一份 Better NXU，确认 Network 中不再请求该开发入口。不要注销 zylib 的 Service Worker，阅读页面本身也依赖它。持续修改代码时可使用 `pnpm dev:build`；构建完成后仍需更新 ScriptCat 中的脚本，详见[开发说明](../dev/development.md#zylib-阅读页的开发入口-mime-错误)。

### 已安装构建脚本，但没有复制提示

该功能匹配直连、校园网 zylib 和 WebVPN 代理的指定 HTML/XML 阅读路径：知网 `kns.cnki.net`/`www.cnki.net` 的 `/reader/xml`、`/xmlRead/trialRead`，以及万方 `f.wanfangdata.com.cn/online/pc/periodical_html`。zylib 阅读地址必须包含有效且唯一的 `__proto__`、`__host__` 参数，或使用指向阅读页的 `/-----https://目标主机/路径` 入口。PDF 阅读器、普通详情页、图片和其他路径不会触发。

进入支持页面时应看到“已开启复制”提示。浏览器或系统拒绝剪贴板权限时，检查 ScriptCat 的 `GM_setClipboard` 权限。无选区或只点击不拖选不会复制。

## 18. 自动关闭失败页无效

先确认设置中的“自动关闭错误网站”已开启。浏览器通常只允许脚本关闭由脚本打开的标签页，手动打开的标签可能无法自动关闭。此时手动关闭即可。

## 19. 评教和团委功能为什么没有执行

自动评教尚未实现，评教任务页只提示手动完成。团委附件验证码识别/自动下载也未实现，脚本在团委站点不执行操作。设置中灰色团委项是兼容占位，不代表即将自动运行。

## 20. 如何重置设置

在 `https://sslvpn.nxu.edu.cn/h/settings`：

- “恢复功能默认值”：保留账号密码、课表 ID、首启状态和密钥，适合修复开关/卡片配置。
- “完全重置”：清除所有内容，适合准备重新配置或处理严重存储异常。

完全重置前备份课表私钥。该操作没有撤销功能。

## 21. 如何提交有效反馈

请提供可复现信息：浏览器、ScriptCat/Better NXU 版本、直连或 WebVPN、页面地址形态、操作步骤、实际结果、预期结果和脱敏控制台错误。

请删除或遮挡：学号、姓名、密码、cookie、token、授权 code/state、私钥、完整课表、教师查询敏感结果和复制正文。截图同样需要脱敏。
