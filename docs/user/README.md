# Better NXU 用户指南

Better NXU 是一个面向宁夏大学网站的浏览器用户脚本，主要改善 WebVPN、统一身份认证、教务课表、信息门户和校内工具的使用体验。

## 重要说明

- 只能使用 ScriptCat 安装和运行。
- 如果点击脚本后出现 Tampermonkey/油猴安装页，请取消。
- 不要同时启用 Better NXU 的旧版、2.x 版或其他重复副本，否则可能重复点击、重复弹窗、重复注入卡片，甚至导致登录失败。
- 自动登录会把账号和密码保存在当前浏览器的 ScriptCat 存储中。只在自己的可信设备上使用，不要在公共电脑保存凭证。
- 滑块验证码支持本地自动识别和最多三次尝试，失败时需手动完成；旧式图形验证码和部分多因子认证仍需手动操作。脚本不改变学校账号权限或网络访问范围。

## 安装

1. 安装 [ScriptCat](https://scriptcat.org/zh-CN) 浏览器扩展。README 也提供了 Microsoft Edge 扩展商店入口。
2. 打开 [ScriptCat 的 Better NXU 项目页](https://scriptcat.org/zh-CN/script-show-page/1429)，点击当前版本的安装入口。2.x 构建产物名为 `better-nxu.user.js`。
3. 确认安装界面由 ScriptCat 打开，检查脚本名称为 Better NXU，然后安装。
4. 在 ScriptCat 脚本列表中确认 Better NXU 已启用。
5. 打开或刷新 `https://webvpn.nxu.edu.cn/`。首次使用会出现配置提示。

从源码自行构建的测试版本，需要先运行 `pnpm build`，再用 ScriptCat 安装 `dist/better-nxu.user.js`。普通用户不要安装 `src/` 中的源码文件。

## 首次配置

在 WebVPN 首页右上角找到“Better NXU”，选择“设置”；也可以直接打开：

```text
https://sslvpn.nxu.edu.cn/h/settings
```

自动登录默认关闭；建议按以下顺序配置：

1. 填写 WebVPN 账号和密码。这里通常是学号和校园网/统一认证密码。
2. 确认是否开启 WebVPN 自动登录。
3. 需要微信多因子快速登录时，再开启“多因子认证（微信扫码）快速登录”。
4. 填写教务系统账号和密码。它们单独保存，不自动复用 WebVPN 凭证。
5. 选择需要的 WebVPN 首页卡片、抢课备用列表、小工具和教务课表美化。

设置修改后会自动保存。账号或密码为空时，相应自动登录开关会被关闭。

## 数据与隐私

Better NXU 会按功能在本地保存：

- WebVPN 与教务账号密码；
- 功能开关和卡片选择；
- 当前账号的课表分享 ID 缓存；
- 课表加密公私钥（如果你主动生成）。

这些数据存储在 ScriptCat 的 Better NXU 存储域。脚本会使用当前学校登录状态请求课表、身份或教师信息，不会替你绕过认证。私钥只在本机保存，项目没有找回服务。

“恢复功能默认值”不会删除账号密码、课表 ID 或密钥；“完全重置”会清除全部数据，包括私钥。执行完全重置前先备份仍需使用的课表解密私钥。

先查看 [常见问题](troubleshooting.md)。反馈时请提供：

- 浏览器和 ScriptCat 版本；
- Better NXU 版本；
- 访问的是直连、校园网 IP 还是 WebVPN 代理；
- 发生问题的页面地址形态和操作步骤；
- 控制台中带 `[Better NXU]`/模块前缀的脱敏错误。

不要提交账号、密码、cookie、token、私钥、完整课表文件或知网/万方复制正文。
