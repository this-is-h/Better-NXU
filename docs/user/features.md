# 功能与设置说明

## 1. WebVPN 与统一认证

### 自动登录

启用 `WebVPN.autoLogin` 后，脚本在可信的宁大统一认证登录页：

1. 检查已保存账号密码和页面错误；
2. 等待登录框，填入账号密码；
3. 勾选“记住我”；
4. 调用页面提供的登录函数或点击提交按钮；
5. 如果出现滑块，自动识别缺口位置并模拟人工拖动完成验证。

滑块自动识别在浏览器本地完成（ONNX 模型识别缺口 + 模拟人类拖动轨迹），验证码图片不会上传。首次识别需要下载运行时、WASM 和约 15 MB 模型，网络较慢时会多等一会儿。直连 IDS 和 WebVPN 均由 ScriptCat 下载静态资源，避免 WebVPN 把资源地址改写成登录页。加载或识别失败、超时、滑块结构变化时会提示手动完成验证。

拖动后会等待验证和跳转。若验证失败、图片刷新，会等新图绘制完成后再次识别，同一流程总计最多尝试三次（首次加两次重试）。第三次仍失败会提示手动验证；图片未刷新时不会因为网络慢或跳转延迟而重复拖动。

旧式图形验证码不会被自动识别。脚本只填账号密码并提示手动输入验证码。

关闭自动登录后，如果已经保存凭证，登录页右下角会显示“Better NXU · 填入已保存账号”。点击只填表，不自动提交。没有保存完整凭证时按钮不会出现。

### 微信快速登录

开启“多因子认证（微信扫码）时启用快速登录”后，脚本会：

- 在统一认证二次验证页选择微信认证；
- 将微信授权参数 `fast_login=0` 改为 `1`；
- 等待并点击微信快速登录入口；
- 遇到特定“授权失败”回调时，尝试重建正确的 WebVPN 回跳地址。

使用时通常需要电脑端微信已经登录，并可能仍要完成授权。页面短暂跳转或出现中间错误页可能是回调修复流程的一部分；如果没有自动恢复，请手动返回 WebVPN。

### WebVPN 首页增强

首页增加：

- Better NXU 菜单：版本、一言、设置、关于、GitHub。
- 搜索栏浮球：打开/关闭原首页搜索区；可设置默认关闭。
- 抢课备用列表：4 个校园网 IP 入口和 4 个 WebVPN 校外入口。
- H 小工具：站内小工具、宁大猫狗图鉴、NXU Charge 外部入口。
- 自定义卡片：教务管理、学工系统、新版信息门户、中国知网、万方数据。已下线的大先生不会再显示。

卡片只提供入口，不保证目标服务本身可用。NXU Charge 等外部项目可能停止维护，出现服务错误不一定是脚本故障。

### WebVPN 失败页

开启“自动关闭错误网站”后，普通 `/wengine-vpn/failed` 页面会尝试关闭当前标签页。浏览器可能阻止脚本关闭非脚本打开的标签页，这是浏览器限制。

H 小工具可直接通过 `https://webvpn.nxu.edu.cn/h/tools` 打开；也兼容页面含专用地址标记的旧失败页入口，不会被当作普通失败页关闭。

### 知网/万方自由复制

直连、校园网 zylib 认证入口或 WebVPN 打开以下阅读页时，脚本会提示“已开启复制”。选中文字并松开鼠标后，文本自动写入剪贴板：

- 知网 `kns.cnki.net`、`www.cnki.net` 的 `/reader/xml` 和 `/xmlRead/trialRead` 阅读页。
- 万方 `f.wanfangdata.com.cn` 的 `/online/pc/periodical_html` 阅读页。

无选区时不会复制。PDF 阅读器、图片、其他阅读路径和网站原生下载权限不在该功能范围内。

校园网访问使用 `zylib.nxu.edu.cn` 的图书馆身份认证入口，阅读页通过 `__proto__`、`__host__` 参数标记真实平台；校外使用 WebVPN。三种入口共用上述阅读增强，直接访问平台时仍需自行登录。

### 知网阅读滑块

知网阅读页出现“请向右滑动验证”的无缺口滑块时，脚本会尝试拖至轨道右端，无需下载识别模型。同一控件只自动拖动一次，同页最多处理三次新出现的控件；等待页面响应时不重复提交。若网站未接受拖动，可直接手动完成，手动按下滑块会停止自动操作。

## 2. 教务系统

### OCR 自动登录

启用 `Jwgl.autoLogin` 后，脚本读取教务验证码图片，首次可能需要下载 OCR worker、WASM 和英文模型，耗时较长。识别成功后填入教务账号、密码和验证码并提交。

OCR 失败、加载超过约 45 秒、识别超过约 30 秒、学校更换表单或验证码类型时，脚本会停止自动流程并提示手动输入。它不会无限重试。

### 自定义菜单

默认在教务主页左侧菜单增加“全部学期成绩”，进入历史课程成绩页。学校调整菜单结构后该入口可能无法插入，但原教务页面仍可手动使用。

### 课表美化

默认开启。脚本解析每个课表单元格并重新排版课程、教师、教室和周次，处理：

- 多名教师和同一单元格多种安排；
- 单双周和离散周次；
- 教师为空、课程名/教师名特殊排列；
- 合并行列导致的实际星期和持续节次。

关闭后保留原教务课表，同时仍会尝试提供导出栏。

### 课表导出

课表上方提供：

- 图片：截取当前课表，2.5 倍比例。直连域名、校园网 IP 和 WebVPN 代理形态均支持；WebVPN 下生成时间可能稍长。
- JSON：导出 Better NXU Schema 2.0，可选择直接或加密。
- Excel：包含“课表”和“课程明细”两个工作表。

如果教务 DOM 变化，解析结果可能缺课程或周次。导出后应先抽查文件，不要把未核对的数据直接用于重要安排。

## 3. H 小工具

详细步骤见 [课表与小工具](schedule-tools.md)。当前包括：

- 在职教师工号查询：按姓名查询，显示姓名、工号、单位；点击结果复制工号。
- 个人课表：自动获取当前账号课表，也可输入门户课表链接或上传 JSON。
- 课程总览：课程数、总课时、实际课次、教学周和每周课时分布。
- 个人课表：总体或按周查看课程安排。
- 个人空课表：区分完全空闲、只有线上课可协调和有课。
- 空课表生成：导入多人 JSON，生成共同空闲分析并导出 Excel/图片。
- 课表密钥管理：生成、复制、显示/隐藏和重新生成公私钥。

进入工具页时会在后台打开信息门户和学工系统代理页，约 5 秒后尝试关闭。这是为课表 ID 和身份验证准备登录状态，不代表脚本上传了数据。

## 4. 新版信息门户

在 `portal.nxu.edu.cn` 的应用中心 `#/hall`，脚本向 iframe 中增加四组入口：

- Better NXU - 常用：学工系统、双创平台、实验室安全教育平台。
- Better NXU - 教务系统：教务系统和 4 个备用入口。
- Better NXU - 图书馆：图书馆、知网、万方、维普、Web of Science、PubScholar 等。
- Better NXU - H 小工具：项目提供的工具入口。

门户是单页应用。脚本监听前进、后退和内部导航；从应用中心切走再切回时会重新注入，不应不断重复卡片。

自定义卡片通过点击或聚焦后按 Enter 打开新标签页：

- 常用、教务和图书馆总入口跟随系统：校内直接访问，WebVPN 由系统转换。
- 知网、万方、维普和 Web of Science：校内进入 zylib 认证入口；WebVPN 打开对应平台的代理入口。
- H 小工具组全部项目及 PubScholar：始终按指定地址打开，不经过 WebVPN 改写。H 小工具本身的指定地址就是 WebVPN 工具页。

## 5. 实验室安全教育平台

在平台入口页，脚本识别“点击登录”并进入登录路径；在认证页识别“统一身份认证登录”并自动点击。后续统一认证仍遵循 WebVPN/IDS 自动登录设置。

## 6. 评教、团委和其他限制

- 评教系统：自动评教尚未实现。进入已识别任务页只显示提示，不自动选择或提交任何评价。
- 团委官网：附件验证码识别和自动下载当前未实现。设置中的两个团委开关是历史兼容占位，处于禁用状态。
- 无感保活、自动抢课等 README 中曾列为计划的能力当前不应视为可用功能。

## 7. 设置项详解

### WebVPN

| 设置               |     默认 | 说明                                 |
| ------------------ | -------: | ------------------------------------ |
| 自动登录           |     关闭 | 填充并提交统一认证，需手动开启       |
| 微信多因子快速登录 |     关闭 | 自动选择微信、修复扫码/回调流程      |
| 抢课备用列表       |     开启 | 显示 8 个备用卡片                    |
| 工具列表           |     开启 | 显示 H 小工具卡片组                  |
| 自定义卡片         | 五项全选 | 可逐项关闭；旧版“大先生”值不会再渲染 |
| 默认关闭搜索栏     |     开启 | 首页加载后收起搜索区，可用浮球打开   |
| 自动关闭错误网站   |     关闭 | 尝试关闭普通 WebVPN 失败页           |

### 教务系统

| 设置             | 默认 | 说明                                  |
| ---------------- | ---: | ------------------------------------- |
| 自动登录         | 关闭 | 使用 OCR 识别验证码并提交，需手动开启 |
| 自动美化课表     | 开启 | 重排课表单元格                        |
| 全部学期成绩菜单 | 选中 | 在教务左侧栏增加入口                  |

### 设置页功能

- ScriptCat 原生配置：打开脚本管理器提供的原生配置入口；可用性取决于 ScriptCat。
- 恢复功能默认值：恢复开关、卡片和菜单，不清凭证、课表数据或密钥。
- 完全重置：清除凭证、全部设置、首启状态、课表 ID 和课表密钥，不可撤销。
