# 课表与小工具

## 1. 打开工具页

登录 WebVPN 后，在首页“H - 小工具”中点击“站内小工具”，或打开：

```text
https://webvpn.nxu.edu.cn/h/tools
```

Better NXU 会直接接管该地址为工具页。如果 WebVPN 将它转到带专用地址标记的失败页，仍会正常打开工具。首次进入会后台预热信息门户和学工系统登录态，等待几秒再使用“课表信息”成功率更高。

## 2. 教师工号查询

1. 选择“在职教师工号查询”。
2. 输入教师姓名，按回车或点击“搜索”。
3. 结果按三列显示姓名、工号和单位。
4. 点击教师条目，工号会复制到剪贴板。

连续搜索会取消上一次请求。最多读取 100 页结果。提示“WebVPN 登录已过期”时，先重新登录 WebVPN/相关代理页面再试；提示结果格式异常通常表示学校接口发生变化。

## 3. 获取个人课表

进入“课表信息”后，脚本优先自动获取当前 WebVPN 登录账号的课表：

1. 从本地读取之前缓存的课表 ID；
2. 没有缓存时，请求信息门户日历卡片的分享接口；
3. 使用 `https://portal.nxu.edu.cn/cal/<课表ID>` 获取 ICS；
4. 解析并规范化为 Better NXU Schema 2.0。

如果自动获取失败，可以：

- 输入完整链接，例如 `https://portal.nxu.edu.cn/cal/1526230487620710400`；
- 只输入至少 6 位的课表 ID；
- 上传 Better NXU 2.0 JSON 文件。

上传文件必须是 `.json`。明文内容上限 5 MB，加密文件整体上限 7 MB。旧版 JSON 会提示只支持 Better NXU 2.0。

## 4. 查看个人课表

### 课程总览

显示本学期课程门数、总课时、实际课次、教学周数和每周课时柱状分布。点击“导出图片”保存当前总览。

### 个人课表

“总体”展示整学期安排；选择具体周次只显示该周课程。同一时间有不同周次/教师/教室安排时，会在课程块中分项显示。可导出当前视图图片。

### 个人空课表

按星期和 1-10 节显示空闲状态。工具会区分：

- 完全空闲；
- 只有线上课程，可能可协调；
- 有线下或不可协调课程。

可在“总体”或具体周次间切换，并导出图片。

## 5. 导出图片与个人 JSON

### 图片文件名

在“课程总览”“个人课表”或“个人空课表”点击“导出图片”时，先确认用于文件名的姓名：

- 已配置 WebVPN 学号时，可选择使用该学号对应的姓名；获取失败时转为填写姓名。
- 选择“填写姓名”或未配置学号时，只需填写真实姓名，无需输入学号；取消则不导出。

图片保存为“姓名 - 课表.png”。填写的姓名仅用于本次图片命名，不会覆盖课表身份信息，也不会替代 JSON 导出的身份核验。确认期间切换课表、视图或周次时，请重新发起导出。

### JSON 身份验证

JSON 导出只允许当前登录账号本人的远程课表：

- 自动加载的当前账号课表可以导出；
- 手动输入的链接只有与本机缓存的当前账号课表 ID 相同才可以导出；
- 上传的 JSON 只允许查看，不能再次导出为“本人课表”。

导出时可能需要确认或输入学号。脚本使用学工系统接口核对该学号是否与当前 WebVPN 登录账号一致，并把姓名写入课表 owner。输入别人的学号会被拒绝。

接着选择：

- 直接导出：任何取得文件的人都能查看。
- 加密导出：使用当前公钥或粘贴接收方公钥，只有对应私钥能打开。

## 6. 从教务系统导出

进入教务系统个人课表页面，使用课表上方按钮：

- 导出图片：直连域名、校园网 IP 和 WebVPN 代理形态均可使用；WebVPN 下生成时间可能稍长。
- 导出 JSON：同样支持直接或加密导出。
- 导出 Excel：生成课表总览与课程明细。

教务导出的 JSON 可用于多人空课表。导出后检查姓名、单双周、教师和教室是否正确，尤其是在学校刚调整课表页面之后。

## 7. 多人空课表

1. 让每位成员从教务系统导出 Better NXU 2.0 JSON。
2. 打开工具页“空课表生成”。
3. 点击“添加人员”，可一次选择多个 `.json` 文件。
4. 加密文件会尝试本机私钥；不匹配时要求粘贴对应私钥。
5. 页面按星期和节次展示每位成员的空闲周次，以及全员汇总状态。
6. 可删除单个成员，或导出 Excel/图片。

同一批文件若使用相同 `kid`，成功输入一次私钥后会在当前页面会话中缓存，后续复用。取消提供某个 keyId 的私钥后，同批对应文件会跳过，不会反复弹窗。

工具按整学期汇总时，会分别标记完全空闲、只有线上课可协调、部分时段可用和无人空闲。最终安排仍需结合临时调课、考试周和未录入事项人工确认。

## 8. 课表密钥管理

### 第一次生成

1. 打开“课表密钥管理”。
2. 点击“生成课表密钥”。
3. 复制并备份解密密钥（私钥）。
4. 把加密密钥（公钥）发给需要向你发送课表的人。

公钥以 `-----BEGIN PUBLIC KEY-----` 开头，可以分享。私钥以 `-----BEGIN PRIVATE KEY-----` 开头，只能本人保管。

### 给别人发送加密课表

1. 向接收方索要他的公钥，不要索要私钥。
2. 导出 JSON 时选择“加密导出”。
3. 选择“粘贴接收方加密密钥”。
4. 粘贴完整公钥并导出。
5. 把生成的 JSON 发给接收方。

### 打开加密课表

上传加密 JSON 时，脚本先尝试当前本地私钥。如果文件是用其他公钥生成的，会要求粘贴对应私钥备份。没有对应私钥无法解密，项目维护者也不能恢复。

### 重新生成和备份

重新生成会替换当前本地密钥对。旧加密文件仍只接受旧私钥，因此应在重新生成、完全重置、清浏览器数据、重装扩展、换浏览器或换设备前备份旧私钥。

不要把私钥发到群聊、网盘公开链接、Issue、反馈平台或让任何人“代为排查”。私钥泄露后，所有用对应公钥加密的课表都可能被解密。

## 9. 文件兼容与限制

- 只支持 `schemaVersion: "2.0"` 的 Better NXU 课表。
- 普通 JSON 可被任何文本工具读取；加密 JSON 是五字段信封，不会直接显示课程内容。
- 文件名相同的多人课表再次添加时会替换页面中的同名条目。
- 页面刷新后，已上传文件和临时输入的外部私钥缓存会消失；本地生成的当前密钥对仍保存在 ScriptCat。
- 课表工具不能感知临时停课、调课或尚未同步到学校系统的数据。
